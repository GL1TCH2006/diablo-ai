SECTION 5: PYTHON AND SUBPROCESS EXECUTION RISKS
================================================================================

5.1 Terminal.execute (tools/terminal.py)
- Runs PowerShell commands via subprocess.Popen
- Protections: destructive_command_reason() blocklist, terminal_blocklist,
  terminal_auto_allow patterns, session blocks, confirmation required for SENSITIVE
- Risk: Commands run with user privileges. Not sandboxed.
- Documented in FINAL_AUDIT_REPORT.txt as explicit limitation.
- No sandbox boundary claims made.

5.2 python.run_script (tools/python.py)
- Runs Python scripts with Diablo's privileges
- Path containment via allowed_roots + path_is_within()
- Permission level: SENSITIVE outside allowed roots, NORMAL inside
- Risk: Full user privilege execution. No sandbox.
- Documented limitation.

5.3 BlenderRunner (blender/runner.py)
- Runs blender.exe via subprocess.Popen with supervised termination
- Bounded output (64KB retained, rest dropped but drained to prevent deadlock)
- Terminate → Kill escalation with bounded grace periods (5s each)
- Cancellation token honored, child reaped
- Typed errors: NotFound, Permission, Spawn, Timeout, Process, Protocol, Script, Cancelled
- No shell=True, arguments passed as list
- Risk: Blender Python scripts execute arbitrary code. Mitigated by:
  - Capability layer serializes access via session lock
  - Operation inventory defines mutating vs read-only
  - Session revalidation after forced termination
  - User must authorize paths via allowed_roots

5.4 Voice TTS (voice/text_to_speech.py)
- Runs PowerShell with System.Speech.Synthesis.SpeechSynthesizer
- Runs in background thread (daemon), join with timeout when `now=True`
- TTS availability probe in edge_companion.py caches result
- Risk: Low. Only speaks pre-formatted status messages.

5.5 Overall Assessment
- No unguarded subprocess execution paths found
- All subprocess calls use explicit argument lists (no shell=True)
- Path containment enforced at tool registry level
- Permission checks before every tool dispatch
- Cancellation tokens respected at dispatch, during, and after execution
- No secrets in subprocess arguments (redaction at logging/evidence layer)
