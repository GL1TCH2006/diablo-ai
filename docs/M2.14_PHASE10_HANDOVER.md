## 3. The defect Phase 10 found

A repair loop reported a **correct** repair as still broken, intermittently.

CPython validates a cached `.pyc` against the source mtime **in whole seconds**
and its **byte size**. An edit that preserves a file's length and lands in the
same second as the previous test run leaves a cache that looks valid, so the
next run imports the pre-repair module.

Reproduced 2 of 3 attempts; `PYTHONPYCACHEPREFIX` redirection removed it in
3 of 3. Real impact: the model is told its right answer was wrong.

**This class of bug is the reason Phase 10 existed.** It only appeared under a
real agent loop doing edit-then-verify in quick succession.
