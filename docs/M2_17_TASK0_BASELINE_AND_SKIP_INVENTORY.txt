F. STRUCTURAL GAP FOUND - NOT VISIBLE AS A SKIP
================================================================================

  Classification: M2.17-ACCEPTANCE-GAP.

  No test file in test_m217_* references DIABLO_REAL_MODEL_TESTS. Verified by grep.

  The three M2.17 real-model probes are *scripts*, not pytest tests:

    tests/real_model_autonomy.py
    tests/real_model_desktop_selection.py
    tests/real_model_edge_companion.py

  None of them matches pytest's default collection patterns (`test_*.py`,
  `*_test.py`), and `pytest tests --collect-only` confirms none of the three is
  collected. Verified directly.

  Consequence, stated plainly: **M2.17's real-model evidence currently lives
  entirely outside the test suite.** Not skipped - absent. There is no pytest test,
  passing or skipped, that exercises the M2.17 autonomy path with a real model. A
  reviewer running the suite sees 3585 green and cannot tell that real-model goal
  completion has never succeeded.

  This is the single most important finding in Task 0, and it is directly in scope
  for the primary objective: Tasks 9, 10 and 18 require a real production-path
  proof, and the right shape for that proof is a gated pytest test in the repository
  that states its own preconditions - not a script nobody's CI will ever run.

  Note this is not a criticism of the probes: they work, and they produced the
  evidence the previous audit relied on. It is a statement about where that evidence
  lives.
