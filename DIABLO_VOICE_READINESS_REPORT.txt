================================================================================
RECOMMENDED IMPLEMENTATION APPROACH
================================================================================

If implementing local STT (Phase 6):

1. **Use faster-whisper** for local STT:
   - CPU and GPU support
   - Good accuracy/speed tradeoff
   - No cloud dependency

2. **Use pvporcupine** for wake word:
   - Lightweight, efficient
   - Requires access key (free tier available)
   - Cross-platform

3. **Use sounddevice or pyaudio** for microphone capture:
   - sounddevice: simpler API, good Windows support
   - pyaudio: more mature, lower latency

4. **Implement with explicit user control**:
   - Microphone activation via UI button (not always-on)
   - Bounded recording duration
   - Clear visual indicator when recording
   - No persistent audio retention

5. **Integration with existing architecture**:
   - Voice commands route through existing cancellation system
   - STT results treated as text input to agent
   - No changes to agent core needed
