SECTION 1: OBJECTIVE
================================================================================

Fix the Windows process-tree termination gap in `BlenderRunner._stop()` identified
in the DIABLO_EXECUTION_SECURITY_AUDIT. The Blender runner was using only
`proc.terminate()`/`proc.kill()` which only terminates the immediate Blender
process, leaving child processes (spawned via `execute_script` with
`subprocess.Popen`) running as orphans.
