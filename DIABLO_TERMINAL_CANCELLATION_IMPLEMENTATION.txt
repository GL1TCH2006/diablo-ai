SECTION 3: CANCELLATION LIFECYCLE & GUARANTEES
================================================================================

1. PRE-LAUNCH CHECK
   - Cancellation token checked before Popen()
   - Returns cancelled=True immediately if already requested

2. DURING EXECUTION
   - Polling loop (50ms interval) checks token and deadline
   - Cancellation token from _tool_context.cancellation_token

3. ON CANCELLATION
   - Primary: taskkill /T /F /PID <pid> (Windows process tree termination)
   - Fallback: terminate() → wait 5s → kill() → wait 5s → block on reap
   - Returns cancelled=True in ToolResult

4. ON TIMEOUT
   - Same terminate→kill sequence
   - Returns timed out error (cancelled=False)

5. CLEANUP
   - Output reader threads joined (64KB bounded streams)
   - Pipes closed
   - Process always reaped (proc.wait() in finally block)

6. OUTPUT BOUNDING
   - 64KB per stream retained, excess dropped but counted
   - Truncation marker added if output exceeds limit

SECTION 4: PROCESS-TREE TERMINATION BEHAVIOR
================================================================================

Windows (Primary):
------------------
- Uses taskkill /T /F /PID <pid> to terminate entire process tree
- This kills the PowerShell process AND any children it spawned
- This is the PRIMARY path on Windows (sys.platform == "win32")

Fallback (Unix / Windows if taskkill fails):
-------------------------------------------
- Standard terminate() → wait 5s → kill() → wait 5s → block on reap
- Only terminates immediate child process
- Process descendants may survive on Unix

Guarantee:
----------
- Process tree termination is GUARANTEED on Windows via taskkill /T
- On Unix, only immediate child is terminated (documented limitation)
- Process is ALWAYS reaped (wait() in finally block)

Edge Cases Documented:
---------------------
- Process already exited: returns immediately
- taskkill fails: falls back to standard terminate/kill
- Process survives kill: logs error, returns False
- Cancellation during output reading: drains pipes first
