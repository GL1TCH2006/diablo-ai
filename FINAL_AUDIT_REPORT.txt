SECTION C: ARCHITECTURE
================================================================================

Agent routing:
  - Single authoritative Agent (core/agent.py) owns TaskManager, Executor,
    PermissionManager, VerificationLedger, planner, debug loop.
  - Model router (ai/model_router.py) with adaptive selection (fast/strong),
    project preference, force8b/force14b modes, escalation after verify-fail.
  - Ollama backend (qwen3:8b, qwen3:14b, qwen3:latest); offline mode available.
  - No competing agent framework (no CrewAI). No second agent pipeline.

Tools:
  - Single ToolRegistry (tools/__init__.py) with ~74 registered tools.
  - Permission levels: SAFE/NORMAL/SENSITIVE/BLOCKED, evaluated per call.
  - Policy gates: git_branch_policy, git_push_policy, git_restore_policy (all
    default "blocked"), terminal blocklist, destructive-command detection.
  - Capability bridge (tools/capability_bridge.py) exposes Blender, Vision,
    Desktop Workflow, Windows capabilities through capability.execute tool.

Memory and rules:
  - ConversationStore, PreferencesStore, ProjectMemory, MemoryStore.
  - RuleEngine with block/allow rules, scoped by project.
  - Secret redaction in goals, memory, FailureObservation evidence, logging.
  - Memory writes are explicit (policy: "explicit"), never implicit.

Task state:
  - TaskManager with states: pending, active, completed, failed, cancelled.
  - StepStatus: PENDING, RUNNING, DONE, FAILED, CANCELLED, SKIPPED, BLOCKED.
  - VerificationState: NOT_RUN, PASSED, FAILED, NOT_REQUIRED, UNVERIFIED.
  - RecoveryPolicy: RETRY_STEP, RERUN_VERIFY, ESCALATE_MODEL, SKIP_STEP, ABORT,
    NONE. Cancellation dominates all recovery actions.
  - Checkpoints/snapshots via SnapshotManager, linked to task records.

Blender:
  - BlenderController (detection, cached, validates executable still exists).
  - BlenderCapabilityLayer (serialized session .blend, cancellation scope,
    session revalidation after forced termination, isolated work_dir).
  - BlenderRunner (supervised Popen, bounded output, terminate-then-kill,
    typed errors: NotFound, Permission, Spawn, Timeout, Process, Protocol,
    ScriptError, Cancelled).
  - diablo_blender_ops.py (Blender-side dispatch: inspect, create, modify,
    transform, material, camera, light, script, save, export, render).
  - BlenderCapabilityAdapter in capability bridge (capability.execute).

Companion:
  - CompanionController (ui/companion_state.py): 7-state machine, explicit
    transition table, worker thread for backend submission, cancellation
    requested (not outcome), terminal task ID tracking, goal projection.
  - FloatingCompanionApp (ui/companion.py): Tk view, status dot/label, activity
    log, compact mode, always-on-top, polling render loop.
  - EdgeCompanionApp (ui/edge_companion.py): edge-docked variant, persona
    formatting, TTS with availability probe.
  - UIController (ui/controller.py): headless controller, worker thread,
    event queue, state transitions, cancellation.

Voice:
  - VoiceService (voice/service.py): wires STT, wake-word, TTS, command router,
    interruption manager, pipeline.
  - TTS: SapiTTSBackend (Windows SAPI via PowerShell), MockTTSBackend,
    OptionalNeuralTTSBackend (stub, deferred).
  - STT: MockSpeechToTextBackend, UnavailableSpeechToTextBackend,
    LocalSpeechToTextBackend (detects faster_whisper, not implemented).
  - Wake-word: MockWakeWordDetector (text prefix match), DisabledWakeWordDetector.
  - CancellationToken, InterruptionManager (task-level cooperative cancellation).
  - VoicePipeline, VoiceCommandRouter, VoiceOutputRouter, VoiceUIAdapter.
  - voice_status() reports honest capability status (no false claims).

Safety:
  - PermissionManager.evaluate(): BLOCKED for destructive commands, session
    blocks, user preference deny/allow, confirmation for SENSITIVE tools.
  - path_is_within(): containment against allowed_roots + BASE_DIR.
  - destructive_command_reason(): shell-native destructive invocation detection.
  - Secret redaction: logging_setup.redact(), FailureObservation redaction,
    goal metadata redaction, verification evidence digests (not raw content).
  - Cancellation: cooperative token, checked at dispatch, during execution,
    after execution; never retried, never reported as success.

    test_m216_ui_event_stream.py (event stream redaction).

  - Terminal.execute runs via PowerShell with blocklist protection.

  - BlenderRunner uses supervised Popen with bounded terminate-then-kill.
  - Verified by test_terminal.py, test_blender_controller.py (runner errors).

Cancellation:

  - Verified by test_phase3_verification.py.

Task verification:
  - VerificationState: PASSED requires observed evidence; FAILED never upgrades.
  - observe_file_content: exact byte comparison (newline="" fix applied).
